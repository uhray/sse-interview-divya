# SSE interview exercises

Thanks for coming in. This repo has three short exercises. Each one is self-contained.

| | Exercise | Format | Time |
|---|---|---|---|
| 1 | [Budget allocator](exercises/01-budget-allocator/README.md) | Debug a bug report, pairing with us | ~35 min |
| 2 | [Events API](exercises/02-events-api/README.md) | Review an open pull request | ~20 min |
| 3 | [Feed importer](exercises/03-feed-ingestion-design/BRIEF.md) | System design discussion | ~35 min |

## Setup

Node 20 or newer, nothing else (no database or Docker).

```sh
npm install
npm test
```

## Ground rules

- Think out loud. We're interested in how you work, not just the result.
- Use the tools you'd normally use: your editor, docs, search. Ask us if you're unsure
  whether something is fair game. Your interviewer will tell you at the start whether AI
  assistants are in bounds today.
- Ask questions whenever you like. Some details are left out on purpose, and in real
  life you'd ask.
- Not finishing is fine.
